# Editor control parity

Source audit against `HEAD` for `components/subtitle-styling.tsx`, `components/word-style-popover.tsx`, `components/transcript-sidebar.tsx`, and their wiring in `components/main-app.tsx`. This records the original controls and the implemented redesign locations. It does not claim runtime verification of the latest changes.

The panel comparison found no removed setting values, slider ranges, or action handlers. The initial redesign put several controls inside a closed **Advanced options** section. The implemented layout below makes person effects visible again.

## Source evidence

- [Style controls](../components/subtitle-styling.tsx): original and redesign control values, ranges, and update handlers match. Person effects are visible in Style; video-background controls are in Camera.
- [Word controls](../components/word-style-popover.tsx): all original font, size, color, effect, emoji, clear, and reset handlers remain.
- [Transcript controls](../components/transcript-sidebar.tsx): edit, three-state removal, filtering, B/F assignment, and export handlers remain.
- [Main wiring](../components/main-app.tsx): style state reaches preview and export; transcript updates reach source chunks; split tracking, mask readiness, and word overrides have explicit data paths.

Runtime checks are recorded separately in [redesign validation](../tests/REDESIGN-VALIDATION.md). No runtime result is inferred from this source audit.

Advanced options remains visible in the scrollable Style panel and is no longer collapsible.
